# 4.5–6.0 Teaching scaffold / 教学支架

## 20-minute micro-lesson

| Minute | Stage | Tutor action | Learner action |
|---|---|---|---|
| 0–3 | Warm-up | Explain task instruction and demonstrate a keyword | Identify 2 keywords in the first question |
| 3–7 | Model | Think aloud through one evidence location | Underline corresponding source phrase |
| 7–12 | Guided work | Ask the learner to locate proof for 2 items; provide hints | Explain the TRUE/FALSE/NOT GIVEN distinction |
| 12–17 | Independent try | Hide answers, give 3 fresh items | Answer, cite paragraph and phrase |
| 17–20 | Feedback | Diagnose 1 reasoning error and 1 paraphrase skill | Write a one-sentence takeaway |

## Scaffolding by level

**Around 4.5:** Break long clauses into subject + verb + key modifier; offer a paragraph locator or two possible keywords; use familiar examples; teach one inference boundary at a time.

**Around 5.5:** Ask student to find paraphrases independently; request a one-sentence justification; add distractors that modify quantifiers, dates and cause.

**Around 6.0+:** Shorter hints; contrast competing evidence; introduce a strict timed cycle and self-check for answer scope.

## Preferred Chinese classroom phrasing

- “先看题干究竟断言了什么，圈出 **all / only / after** 这类限定词。”
- “我们去原文找能证明或推翻整句话的证据。”
- “原文只提到了 X，关于 Y 没有信息，所以这道题属于 **NOT GIVEN**。”
- “你找对段落了，下一步要检查程度和时间是否一致。”

## Teacher/learner material boundaries

Make two independent blocks if both are requested:

1. **学生版:** passage, instructions, headings/options, numbered questions, answer sheet.
2. **教师版:** keyed answers, precise evidence, Chinese logic, error notes, suggested 20-minute plan.

Never attach the key below the student handout without a clear boundary when the teacher wants a sendable learner copy.
