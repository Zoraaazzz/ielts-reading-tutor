# IELTS Reading task-type decision guide

| Task | Correct decision process | Frequent trap |
|---|---|---|
| TRUE / FALSE / NOT GIVEN | Compare the complete question proposition with passage facts: entailed / contradicted / undetermined | Treating absent exact keywords as NOT GIVEN, or treating a stronger claim as entailed |
| YES / NO / NOT GIVEN | Evaluate the writer's opinion/claim rather than simply checking factual details | Mixing the printed YES/NO response scale with TRUE/FALSE |
| Matching headings | Read the paragraph's topic sentence + development + conclusion to identify overall function | A heading matches one striking sentence but misses the main idea |
| Matching information | Search for an exact information type (date, example, cause, comparison), then verify | Assuming paragraphs must be used in order, or assuming each only once |
| Matching features | Locate the named person/group/concept and verify who said/did what | Attaching a statement to the nearest name |
| Multiple choice | Test **every** option against passage scope/quantifiers | Picking a partially true option with an extra false clause |
| Sentence / summary / table / note completion | Determine grammatical role, locate phrase, copy permissible word count | Writing a synonym when exact source words are required |
| Short answer | Answer only what is asked, copy words from passage if required | Adding explanation words that exceed word limit |
| Diagram / flow chart | Follow spatial/process relations and labels from passage | Answering from general knowledge rather than source |

## The 3-way logical test

- TRUE / YES: passage entails the claim. Example: "all workshops are held on Saturdays" supports "the workshops take place on Saturdays".
- FALSE / NO: passage entails the claim's negation. Example: "there is no borrowing fee" contradicts "every borrower pays a fee".
- NOT GIVEN: neither statement nor negation is warranted. Example: "volunteers help with repairs" does not establish "all volunteers are qualified electricians".

**Quantifiers & modifiers to watch:** all, some, only, mainly, most, always, never, first, last, before, after, more, less, may, must, likely, caused by, associated with. A shift in scope, chronology, cause, or degree can flip the answer.

## Evidence template

Question keywords: `...`  
Source wording: `...`  
Location: `Paragraph B, sentence 2`  
Logical test: `entailed / contradicted / undetermined`  
Answer: `...`  
Chinese explanation: `...`

For teacher-created NOT GIVEN questions, check that *even after reading the whole passage*, the answer cannot be inferred with certainty. Avoid ambiguous questions that appeal to common sense or real-world facts.
