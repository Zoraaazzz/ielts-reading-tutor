# Content QA checklist

For each item:

- [ ] The printed question instruction matches its answer scale and format.
- [ ] Every answer comes from the assigned passage, including all modifiers in the question.
- [ ] Evidence quote is genuinely present in the indicated paragraph.
- [ ] The supporting quotation is decisive enough for the complete proposition.
- [ ] FALSE is an actual contradiction; NOT GIVEN is genuinely undetermined.
- [ ] Multiple-choice distractors are plausible but clearly refutable or incomplete.
- [ ] Heading choices are about the paragraph's central point; reuse rules are obeyed.
- [ ] Completion and short-answer keys respect exact word limits.
- [ ] A learner-only render omits solutions and explanations.
- [ ] Teacher explanations use concise Chinese and precise English terminology.
- [ ] Passages newly written for practice are labeled original and unofficial.
- [ ] A score calculated on a mini-worksheet is labeled practice accuracy, not an official IELTS band.

Automated validation checks format, evidence presence, question numbering and answer labels. **It cannot verify full semantic entailment**; the tutor/teacher must read the original passage and proofread the logical relationship.
